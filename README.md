saturated oranges, reds and golds against deep teal-blue water and sky, with
the sun, drifting clouds, and sparkling water droplets trailing the leap.
Pure motion and surprise, no text anywhere in the image.

## How to run

Requires Node.js 22+ (no external dependencies).

```sh
npx tsc main.ts --module nodenext --target es2022 --outDir dist
MAKEFUN_OUTPUT_DIR=./output node dist/main.js
```

This copies `sky-koi.png` to `entry.png` (1024x1024) in the output directory
(`MAKEFUN_OUTPUT_DIR` if set, otherwise `/output`).
